Статический многостраничный корпоративный сайт. Сохранены оформление, палитра, структура и фотогалерея исходного проекта. Страницы генерируются `tools/build.py` и публикуются на GitHub Pages.

- Сокращённое: ООО «ЛоджикНав».

- ОКВЭД 26.51.2.
- Адрес для обращений (из ранее представленных материалов): `logicnav@verhost.ru`.

Адрес, ФИО руководителя, дата регистрации, личный ИНН руководителя, состав учредителей и прочие необязательные сведения на сайте и в репозитории не публикуются.

## Форма: только подготовка письма

**Сайт не отправляет содержимое запросов на сервер или в сервисы сбора форм.**

1. Посетитель заполняет форму «Контакты».
2. После проверки полей кнопка «Открыть письмо» вызывает ссылку `mailto:logicnav@verhost.ru` с готовыми темой и текстом.
3. Почтовая программа пользователя откроет черновик. Пользователь проверяет и самостоятельно отправляет письмо.
4. Если приложение не открылось, доступны кнопка «Открыть письмо вручную» и копирование текста обращения.

Никакие вложения через форму не загружаются: файл пользователь прикрепляет в своём почтовом приложении. Для работы нужен настроенный обработчик `mailto:` или почтовая программа. Не стоит ожидать уведомления «письмо отправлено» на сайте, поскольку отправку выполняет пользователь.

Сервисов Formspree, Web3Forms и PHP-обработчика в проекте нет. Настройки `FORM_ENDPOINT` и `FORM_ACCESS_KEY` не используются. JavaScript не содержит `fetch` для отправки заявок.

Примечание: базовая версия сайта по-прежнему получает веб-шрифты Manrope и IBM Plex Sans с Google Fonts (только визуальное оформление, не содержимое форм). Скрипт Яндекс Метрики в текущей версии не активирован, поскольку номер счётчика не задан.

## Размещение на GitHub Pages

1. Загрузите содержимое папки `logicnav-site/` в репозиторий GitHub, ветка `main`.
2. Откройте **Settings → Pages → Build and deployment**, задайте **Source: GitHub Actions**.
3. Workflow `.github/workflows/pages.yml` автоматически определит адрес сайта и соберёт страницы.
4. Для собственного домена создайте в корне файл `CNAME`, содержащий только домен (например, `example.ru`). Настройте DNS и HTTPS согласно требованиям GitHub Pages.

Работа формы через `mailto:` не требует ни серверной настройки, ни ключей, ни платных сервисов.

## Локальная проверка

```bash
SITE_URL=http://localhost:8000 python3 tools/build.py
cd site
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`.

## Структура проекта

```
.github/workflows/pages.yml   Автоматическая публикация
site/assets/css/style.css    Оформление
site/assets/js/main.js       Навигация, фотогалерея, почтовая форма
site/assets/img/            Фотографии изделий, логотипы, favicon
tools/build.py               Все тексты и шаблоны страниц
```

Изображение синей платы LN1YA (`site/assets/img/ln1ya_board-*`) опубликовано на странице LN1YA по решению заказчика. Это 3D-изображение платы из презентации, а не фотография, поэтому подписано как «Изображение». На нём видны подписи контактов платы. Три фотографии красной многоплатной сборки используются на главной, странице «Продукция», странице LN1YA и странице «О компании». Для LN14YA и «Тетива-М» фотографии оборудования не используются: там типографские плашки и информационные карточки.
